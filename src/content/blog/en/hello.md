## Background

This is the first post on my personal tech blog. Here I'll document debug processes, technical research, and experiment results from my projects.

## Why Blog

I often run into interesting technical challenges in my work — maybe a tricky bug that took an afternoon to track down, a deep dive into a framework, or a performance optimization experiment. These experiences are worth recording and sharing.

## Tech Stack

This blog is built with [Astro](https://astro.build/) and deployed on GitHub Pages. It supports bilingual content (Chinese + English), with content generation assisted by the Super-Brain knowledge system.
